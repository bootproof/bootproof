Verifying signatures in your browser…

This file is one HTML document. The ed25519 public key, signature, and signed message for each receipt are embedded inline. The signed message attests that this evidence was produced and has not been altered since signing. The boot logs and observed HTTP responses above are real captures from a real bootproof up run against a real repository — not hand-authored mock data.

Trust ladder. This receipt is signed at the local_developer_signed level — it proves integrity-since-signing, not that the signer's machine was honest. The documented upgrade path is: local_developer_signed → ci_oidc_signed (CI runner with OIDC token) → neutral_runner_signed (BootProof's neutral hosted runner) → transparency_logged (neutral runner + public log entry). The same file format and the same wow experience survive every step up the ladder; only the signer's identity climbs.

Browser fallback. Native Ed25519 in WebCrypto ships in Chrome 137, Firefox, and Safari. For the ~20% of users on older browsers, this file falls back to a pure-JS @noble/curves verifier bundled inline — the receipt never fails to verify silently.
