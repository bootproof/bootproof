The run button
that can't lie.

A single self-contained file. When you opened it, your browser ran crypto.subtle.verify('Ed25519', …) locally — no network, no install, no account. If a single byte of any signed message is altered, the receipt's verdict collapses with it. That is the whole point.

Verifying signatures in your browser…

This file is one HTML document. The ed25519 public key, signature, and signed message for each receipt are embedded inline. The signed message attests that this evidence was produced and has not been altered since signing. It does not by itself prove the signer's machine was honest — that requires a neutral hosted runner, which is the documented upgrade path for higher-stakes use cases.

The honesty contract: no verified boot without an observed health signal; no success rendering for skipped steps; signed failed attestations for refusals and execution failures. A green check that survives tampering would defeat the entire product.
